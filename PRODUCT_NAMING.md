# Product naming recommendation

Status: working recommendation for the Health-a-thon deck and MVP. Team confirmation is still required before a public rebrand.

## Recommendation

Use **Continuity Loop**.

Descriptor: **Clinician-controlled goals-of-care follow-up and verified handoff.**

Confidence: high that judges understand the meaning immediately; moderate that it is distinct in ordinary web search; low that it is legally clear until Indian trademark, company, app-store, social-handle and domain checks are completed.

The name is immediately legible to the judging panel: it says that the product keeps care connected over time and closes the loop after a conversation. It also preserves the existing public MVP URL: `https://continuity-loop-healthathon.vercel.app/`.

## Web collision screen

This was a visible-web screen on 13 September 2026, not trademark clearance. Exact-name searches did not surface a direct product or company using "Continuity Loop" as its name. A fresh search did find the phrase used descriptively by [EziiSuite](https://sadirasoft.com/) and [Tapza.ai](https://www.tapza.ai/), so the phrase is not legally guaranteed to be available.

Names rejected because a healthcare product, company, app, or closely related clinical use was already visible:

- `CareThread` - existing shared care-log product.
- `CareLoop` - existing care-coordination and referral platforms.
- `CareRelay` - existing family and hospital handoff products.
- `CareBridge` - existing healthcare companies and apps.
- `CareTrail` - existing personal-health organizer and a trademark application.
- `CareWeave` - existing medication-adherence platform.
- `CareLoom` - existing caregiver and home-care products.
- `CareStitch` - existing home-health scheduling platform.
- `CareStory` - existing dementia-care product and earlier clinical-record use.
- `CareBrief` - existing health-report products.
- `CareContext` - existing Indian patient-owned health-record infrastructure company.
- `CareTrace` - existing follow-up and documentation products.
- `CareKeep` - existing care-coordination products.
- `CareCurrent` - existing in-home care coordination product.
- `Patient Thread` and `Threadline` - existing clinical products.
- `Samvaad` and `Sutradhar` - existing health or health-adjacent products and programmes.

The final choice should still be checked against Indian trademark records, company-name records, app stores, social handles, and the domain options before incorporation or launch.
