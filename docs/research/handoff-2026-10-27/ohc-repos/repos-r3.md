### Top findings for Sahara

1. **care_pressure_sore_fe is the best asset here.** MIT-licensed front/back body-map SVGs with 40 regions, plus a ready schema for wounds (region, length and width in cm, exudate, tissue type, note). It can be reused directly for pressure-sore charting and adapted as a pain-location body map. Files: `public/images/pressure-sore-anterior.svg`, `public/images/pressure-sore-posterior.svg`, `src/lib/bodyPaths.json`, `SCHEMA.md`, `src/lib/group.ts`. Repo: https://github.com/ohcnetwork/care_pressure_sore_fe. Sahara would need to add a lasting wound ID to track one sore over time.
2. **A family app can only talk to CARE through the patient OTP login.** Per `care_scaffold/skills/care-auth-contexts/SKILL.md`, patient tokens are filtered by phone number and read-mostly. They cannot reach staff endpoints. So Sahara can read a patient's own records only if a hospital runs CARE and has that patient's phone number on file. Nothing in this lane lets anyone pull patient data without a hospital's account.
3. **The home-visit location pattern is simple to copy.** care_patient_geo_fe just appends a Google Maps https link to the address text (`src/lib/geo.ts`). The idea transfers to Android easily. There is no separate coordinate field.
4. **Notification events are worth copying as a design.** care_notifications_fe covers booking reminders, report ready and medication low-stock or near-expiry, all for staff. CARE has no patient SMS or push in this lane. Sahara would build its own FCM notifications using the same event list.
5. **Free data:** `care_onboarding_fe/data_source/` (MIT) has CARE-format questionnaire JSON, activity definitions and states/districts. The SBOM JSON is public with no auth. care_report_templates (discharge, treatment and medication summaries) has no licence: ask OHC before copying.
6. **Open endpoints in these plugins are harmless.** The only ones are health/ping: `/api/care_odoo/ping/` and `/api/care_people_be/health`. Every data endpoint requires a staff JWT, and some need a superuser.
7. **Licence gaps:** care_report_templates and care_scaffold have no licence. care_notifications_fe and care_patient_geo_fe declare MIT only in package.json, with no LICENSE file. care_people_fe has an MIT LICENSE file but says ISC in package.json.
